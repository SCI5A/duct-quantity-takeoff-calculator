# Duct Quantity & Accessories Calculator

حاسبة كميات الدكت وملحقاته، جاهزة للنشر على GitHub Pages.

## تشمل
- Rectangular / Round Duct
- Duct area + waste
- Sheet weight
- Insulation area, thickness and waste
- Insulation adhesive kg
- Insulation tape
- G-Flange
- Flange Corners
- Cleats / Clamps
- Gasket / Sealing Tape
- Duct Silicone Sealant
- Bolts & Nuts
- BOQ
- Local Storage
- CSV export
- Print / PDF

معدلات الغراء والشريط والسيليكون قابلة للتعديل حسب Technical Data Sheet.
المعادلات تقديرية لأغراض Quantity Takeoff ويجب مراجعتها مقابل مواصفات المشروع وتفاصيل التصنيع.

## GitHub Pages
ارفع الملفات إلى فرع `main`، ثم فعّل GitHub Pages باستخدام GitHub Actions.
